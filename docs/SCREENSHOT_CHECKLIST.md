# Screenshot Checklist

Capture the following screenshots for the README and portfolio. Use demo/anonymized data — no real personal photos, messages, or sensitive information.

## Required Screenshots

1. **Home Screen** — "Bugün Biz" with daily message card, next special day countdown, love reason, and Feyzi AI shortcut
2. **Calendar** — Monthly calendar view with colored event dots and event list for a selected day
3. **Memories** — Timeline view with photo cards (use demo photos)
4. **Memory Detail** — Single memory with photo, date, note, and mini map
5. **Feyzi AI Chat** — Conversation showing tool calling (e.g., adding a calendar event with confirmation card)
6. **Mood Tracking** — Mood selection and partner mood display
7. **Daily Streak** — Photo streak counter and today's photos
8. **Bucket List** — List with categories and completion states
9. **Special Days** — Special days list with countdown badges
10. **Surprise Box** — Mix of locked, unlockable, and opened surprise cards
11. **Profile** — Profile screen with partner info and pairing section
12. **Login** — Clean login/register screen

## Guidelines

- Use **light mode** for most screenshots (include 1-2 dark mode for variety)
- Capture on iPhone 15 Pro simulator (or equivalent)
- Ensure status bar shows reasonable time (not 9:41 for variety)
- Use placeholder/demo text that looks realistic but contains no real PII
- Export as PNG at 2x resolution
- Save to `docs/screenshots/` with descriptive names:
  - `01-home.png`
  - `02-calendar.png`
  - `03-memories.png`
  - etc.
